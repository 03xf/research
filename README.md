# 无人机火情识别与火源定位研究

这是项目截至 2026-09-28 的**第一批公开快照**。研究目标是从多机可见光（V）与热像（T）视频中识别同一处地面燃烧源，并研究何时能给出有依据的位置。研究状态和撤回的旧结论见 [课题主文档](课题主文档.md)。

## 本次上传

- 根目录：实验、数据审计、检测、跟踪、回放与定位脚本。`server_code/tools/` 补充了服务器独有或与本地不同的工具脚本。
- `b1_b3_candidate_dataset_v1/`：2,401 对候选帧的完整来源索引与检查报告；`样本/候选抽帧/` 提供按录像组分散抽取的 **36 对 V/T 原始抽帧**。这些帧尚未人工确认标签。
- `dji_validation_audit/`：71 对历史验证图像、已有 YOLO 标签及复核决策。原标签含已知错误，使用前须结合审计记录，不能直接视为最终真值。
- `模型权重/`：冻结默认 E2 V/T 和 B2 R2 V 研究候选的 `best.pt`、训练 `args.yaml`；权重由 Git LFS 保存，SHA256 见 `权重校验.json`。
- `定位可行性执行_v1/`、`_dji_preview/`、`火点点位整理_20260927/`：照片观测、遥测、火点身份与几何试算。
- `b2_reports/`、`outputs/B2_fixed_fire/`：B2 历史评估和短回放结果。固定坐标输出的来源是已知 LRF 参考查表，不是逐帧独立视觉定位。

## 数据边界

原始苏州视频约 **166 GiB**，这次暂留服务器；全量候选抽帧、旧烟雾数据、历史训练输出也未全部推送。原始文件和校验清单见 `_tmp_train_audit/`。两篇他人学位论文 PDF、下载缓存以及可能包含人员的激光原始照片没有放入公开仓库。

特别注意：B3 北侧没有可信对应的激光参考；旧 `site_results.csv` 中的 13.28 m 是错误对应下的坐标距离，**不是定位误差**。当前身份以主文档和 `_dji_preview/fire_point_analysis_scope_v6.csv` 为准。

此仓库是实验记录和可继续工作的代码快照。全量重训需要服务器原始数据与相应环境；包内样本可用于检查流程和做小规模诊断，不能代替独立测试。
