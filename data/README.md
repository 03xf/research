# 图片、标签和连续帧

完整图片位于根目录 README 链接的 Release 数据包内，解压后为 `data/images/<SHA256>.jpg`。仓库 `data/samples` 提供少量原尺寸浏览图，标签放在 `data/labels/<标签SHA256>.txt`。

通过 `manifests/image_sources.csv` 可还原每张图片的原文件名、数据版本、历史划分和对应标签；同一图片可能对应多个标签版本。`class_names` 决定类别编号含义。标签是原始历史版本，不因发布而自动成为可靠 GT。

600 张候选补充图未标注；5 段连续帧合计 750 张，具有原视频解码 PTS，但没有完整逐帧人工 GT。导出序列编号与原视频帧号分开记录。模型预测位于 `results/sequences`，不得作为 GT。

浏览样本同时覆盖原有数据、候选抽帧、定位帧、连续帧，以及按现有标签面积选择的最小/最大明火框。弱火、距离、困难负例与误检漏检类别须结合历史复核和失败报告判断，未对未标注样本伪造分类。
