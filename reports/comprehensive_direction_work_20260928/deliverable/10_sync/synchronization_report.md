# Synchronization audit

The 20 selected moments were assembled from V/T file creation-time overlap and per-stream creation tags. `creation_timestamp_diagnostic.csv` reports the observed metadata spreads and paired V/T tag differences. These are **not** camera-clock offset estimates: container timestamps may be file creation times, S telemetry clock alignment was not established against a shared physical event, and no manually tracked moving/ignition landmark spans all UAVs. Therefore ±0.1–2 s geometry/association curves cannot be truthfully estimated from the current labels. Treat all staged cross-UAV frame sets as candidate synchronized views, not validated synchronized observations. A publishable sync study requires repeated common event landmarks across recordings, S subtitle/PTS alignment, and held-out drift validation.
