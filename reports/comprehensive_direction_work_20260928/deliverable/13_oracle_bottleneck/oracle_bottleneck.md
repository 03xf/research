# Oracle bottleneck

The only full oracle decomposition is one B3 three-UAV instant. North remains about 12.68 m wrong with manual anchor and association, so geometry/absolute calibration is limiting there. South manual points yield about 0.71 m under corrected geometry, but the frozen V detector supplies only one usable view, so observation availability is limiting. H is conditionally separable in the one manually labeled B3 event, but cross-event identity truth is absent. T same-case identity and multi-view anchor inputs are missing. Across the dataset, current bottlenecks rank as: (1) independent truth/physical identity and event-level support; (2) source observation visibility and manual anchor quality; (3) shared geometry/calibration/synchronization uncertainty; then model capacity. The rank can differ by scene; the existing oracle grid cannot establish population bottleneck proportions.
