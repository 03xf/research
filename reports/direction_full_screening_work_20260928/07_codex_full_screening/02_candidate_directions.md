# A–N 方向及判别结果

表内“通过”只指本轮预实验出现信号，不表示论文已成立。可复现数据见各目录的 `experiment.py`、`results.json` 和 `failures.csv`。

| 方向 | 本轮判别实验 | 当前判断 |
|---|---|---|
| A 地面火源 anchor | 33 个 V、44 个 T 已匹配点上比较框中心、框底和跨 B3/B4 偏移 | V 有跨批次条件信号；T 的偏移没有收益，缺定位验证 |
| B 时间 anchor | 三帧拖尾中值与同帧人工点比较 | 点误差小幅下降；无相机运动补偿及定位收益证据 |
| C 非配准 RGB-T | 99 个时刻的 SIFT/单应性空间覆盖 | 19/99 达空间支持；普通固定映射降级 |
| D 热像补漏 | 逐点/逐时刻明火覆盖及非火热区误触发 | B3、B4 都有补漏；必须解决状态拒识 |
| E 明火/余热/热背景 | 状态×片段列联与 V/T 检测触发 | 余热仅一段，三类独立测试不成立 |
| F 先验约束多机几何 | 同一人工点的名义/视觉几何 LRF 水平误差 | 4 个明火点仅 2 个改善，B1/B4 退化 |
| G 定位可信度 | 按 ray residual 排序的准确率—覆盖率 | 低残差可保留大绝对误差，单阈值无效 |
| H 跨机同源 | B3 已确认 N/S 组合；B4 火时彩色分割点做探针 | B3 判别强；B4 仅未核实的可行性 |
| I 相机模式光轴 | 有效 LRF bearing 与 gimbal 的分模式、留 session 偏差 | 模式与机型/地点混杂，且不是相机光轴真值 |
| J 背景自标定 | 四批多机 SfM 网络与 B4 LRF | 重建可行；free SfM 绝对定位失效 |
| K 完整链路误差分解 | B3 同一组三机帧补完五级 oracle；其余场景只有手工点/关联下的几何替换 | B3 南火点自动检测缺两个视角，北火点人工点仍有约 12.68 m 误差；不能外推跨事件 |
| L 旧烟雾跨域 | SHA256 split 审计 | 继承划分直接淘汰；需重建独立协议 |
| M 早期小烟 | 去精确重复后的按面积召回 | tiny 存在差距，但没有事件独立早期标签 |
| N 多模态多视角图 | 候选、人工点、跨机同源的真值交集 | 图结构可想象，联合真值图缺失，暂缓 |

不把候选数量、COLMAP 重投影误差、热像亮区或旧烟雾 mAP 当作独立火源定位证据。推荐方向见 `13_final_direction_screening.md`。
