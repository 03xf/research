# H/N：跨机同源与联合观测图

B3 人工确认的 North/South 火源在三 UAV 单时刻形成 8 种 N/S 三元组合。正确 NNN/SSS 最大中位 ray residual 为 0.596 m，错误混合组合最小为 7.996 m；旧几何对应为 1.090 与 8.990 m。这是一个明确的**同场景判别信号**，但 8 个组合复用同 3 台相机和同一时刻，样本数不能记作 8 个独立事件。

本轮另在 B4 火时 COLMAP 网络运行了已有彩色火区探针的隔离版本：按 A/B 分组时最大同组 residual 为 0.113 SfM 单位、最小混组为 1.093，分离约 9.65 倍。这说明 B4 背景图也有几何判别潜力；B4 的彩色分割点仅是启发式区域，第二个火源的物理身份与独立 LRF 坐标未核实，不能称为跨场景关联准确率或米级定位。

H 的下一步是利用**已有** B3/B4 多时刻视频逐帧复核每架无人机看到的物理火源 ID、遮挡和“不确定”，比较 appearance-only、图像邻近、名义遥测几何、校正几何，并以 source ID 一致性、错误合并/拆分和已核验点的水平差评估。若离开 B3 一个时刻后 residual 分离消失，或 B4 身份复核不成立，则降级为几何诊断。

N 的 2401 对 V/T 都未复核为同源。现有五段人工 V/T 片段没有覆盖多 UAV 同时、同一点、同状态的联合真值图。因此 joint graph 目前不能训练或评估，不应把 C、D、H 三个彼此不同样本的结果乘在一起推算性能。
