# Protocol and provenance

- Inputs: staged 20 moments / 298 V/T frames in prior `10_comprehensive_direction_revalidation/02_high_redundancy_multiview`; originals untouched.
- Physical IDs assigned from visible road, tree, fixed pile, char pattern and temporal scene context. B3 N/S mapping retains earlier human site confirmation. Ray residual is not used to create labels.
- All 298 frames received a first visual site/visibility pass. B3_M02 and B4_M02 (34 frames) received a separate second pass by the **same agent**; there was no second human. Source presence agreement 88.2%, five-level visibility agreement 70.6%, source-count agreement 88.2%. Physical pixel-ID placement was not independently double marked.
- 42 manual V marks in four moments are approximate **flame-base proxies** placed on 480×270 contact thumbnails. There are **zero** defensible exact ground-contact marks; no V/T point semantic equivalence is assumed.
- At each moment and source, fit a C0 nominal 3D line intersection from a support UAV subset, exclude the held-out UAV before fitting, project with its S-subtitle pose only for scoring. Enumerate all subsets. Report summaries after collapsing correlated subsets within each held-out source frame.
- S subtitle telemetry was extracted at all 149 V frame offsets. Candidate cross-UAV S wall-time spread spans 0.424–2.241 s. No physical transient was aligned; dynamic temporal scores are unavailable.
- Camera model uses legacy nominal 35 mm equivalent focal convention, fixed principal point (960,540), no measured distortion/calibration. Geometry outputs are diagnostic.
- B1_F1 and B3_N/B3_S accepted LRF sites are external site-level calibration; B2 prefire pile and B4 unrelated repeated LRF observations are not fire Gold for these precise points.
