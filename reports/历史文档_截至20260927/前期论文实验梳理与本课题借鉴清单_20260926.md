# 前期论文实验梳理与本课题借鉴清单

更新时间：2026-09-26  
参考文件：`reference_papers/徐瑞擎毕业论文终版论文(1).pdf`、`reference_papers/赵迪的毕业论文第四版.pdf`

## 1. 两篇论文各自怎么做

两篇论文研究对象都是**无人机森林烟雾**，不是本课题当前的地面明火/热像热点。实验主线基本一致，分为四层：

1. **单帧烟雾检测**：以 YOLOv8n 或其轻量改进版为基础，在自建烟雾框数据集上训练、对比主流检测器和做消融实验。
2. **跨域检测**：把自建数据作为源域，再构造或收集无标签目标域，用 Mean Teacher、伪标签、风格迁移、扩散模型等方法缓解不同场景、光照和气候带来的域偏移。
3. **烟源区域与距离**：先用语义分割找烟雾源头 ROI，再用 ORB-SLAM2 恢复相机运动，通过连续帧三角测量估计烟源距离。
4. **地理坐标和软件**：将视觉相对距离与无人机 GPS、姿态和云台信息融合，换算成经纬度；再部署到 Jetson Nano + Matrice100，做离线视频和软件功能测试。

## 2. 徐瑞擎论文的实验结构

- 检测数据集 `Source-Smoke` 报告 7,969 张图，正负样本为 5,312/2,657，按随机 9:1 分成 7,173 张训练和 796 张测试。
- 检测模型采用 YOLOv8n 改进的 LFSNet，重点是多尺度卷积、轻量化和小目标/复杂背景特征提取。
- 跨域部分使用有标签源域、无标签目标域和测试域，增加伪标签筛选、记忆库、FreeControl 图像合成等环节。
- 定位部分为 `MK-UNet 分割 -> 烟源 ROI -> 优化 ORB-SLAM2 -> 多帧三角测距 -> GPS/姿态坐标换算`。
- 软件部分采用视频采集、检测、定位三模块，服务器训练后导出 ONNX，再转 TensorRT；Jetson Nano 上报告约 16 FPS。
- 五段视频用于软件检测，其中视频 1/2 没有距离和坐标真值，视频 3/4 只有距离真值，视频 5 才同时有距离和经纬度真值。检测报告约 P=89.9%、R=89.2%；经纬度结果主要来自一段有坐标真值的视频。

## 3. 赵迪论文的实验结构

- 检测数据集命名为 `EB-Smoke`，论文同样报告总量 7,969 张、训练 7,173 张、测试 796 张。
- 检测模型为 FastNet，并在此基础上构造 SSDA-FastNet；主要改动包括轻量主干、注意力、知识蒸馏、师生交互、DEADiff 目标域扩充和 CycleGAN-turbo 风格迁移。
- 跨域对比先比较无域适应 YOLOv8n、DA-Faster、MMD、ConfMix、Efficient Teacher、SSDA-YOLO，再针对 SSDA-YOLO 的伪标签和风格迁移问题做改进。
- 定位部分为 `UltraLight VM-UNet 烟雾/烟源分割 -> 动态特征过滤 -> ORB-SLAM2 -> 多帧三角测距 -> GPS/姿态换算`。
- 软件系统也是采集、检测、定位三层，报告约 14 FPS；五段视频中，只有一段同时提供距离和经纬度真值，检测结果约 P=90%、R=89% 左右。

## 4. 对我们最有用的借鉴

### 4.1 把实验拆成四个可验收层

我们可以沿用“检测、时序、位置、部署”四层结构，但目标改为：

1. **V 明火检测**：每帧输出 `flame` 框；
2. **T 热点检测**：每帧输出 `hotspot` 框，并与 V 分开评估；
3. **时序与同源关联**：按 PTS 将 V/T 配对，用轨迹连续性、火点 ID、漏检间隔和无火误报做视频级验收；
4. **位置输出**：B2 先做 `LRF_reference_lookup` 固定场景参考坐标，未知火点再做真正的视觉几何定位；
5. **部署**：记录输入帧率、推理延迟、队列延迟、丢帧、模型输出和坐标状态，而不是只展示一张结果图。

### 4.2 沿用多帧思想，但先用于稳定性

前辈论文用多帧主要是为了三角测距。我们当前没有可靠的每帧地理真值，且 B4 只有近似位置核对，因此先把多帧用于：

- 轨迹确认和断裂统计；
- V/T 时间配对；
- 弱火短暂漏检的容错；
- 连续确认后才允许输出固定参考坐标。

只有在相机内参、云台角度、机体姿态、时间同步和地面源点都完成标定后，才把 ORB-SLAM2/三角测量扩展为未知火点的 `visual_prediction`。

### 4.3 沿用“有真值才报告对应指标”的原则

- 有框标注的数据报告 Precision、Recall、AP50，并按燃烧阶段、小目标、弱火分别统计。
- 有完整视频的数据报告覆盖率、最长连续漏检、轨迹断裂、ID 切换和每分钟误报。
- 有距离真值才报告距离误差；有地面坐标真值才报告坐标误差。
- B4 没有独立坐标真值，只报告稳定识别、轨迹和近似位置画面核对，不写成精确地理定位。

### 4.4 借鉴部署测试的记录方式

保留前辈论文中的模块化接口和 ONNX/TensorRT 方向，但在我们的日志中额外记录：视频组、session、V/T 时间戳、模型哈希、阈值、轨迹状态、坐标来源和 `null` 原因。这样能把“实时输出”变成可复查的逐帧证据。

## 5. 不宜直接照搬的地方

1. **随机按图片 9:1 划分**：视频连续帧高度相似，会把同一场景泄漏到训练和测试。我们按完整视频/session 划分，B4 作为验收候选，并审计历史暴露。
2. **把单个有坐标真值视频代表全部定位能力**：前辈论文的完整经纬度验证主要来自单个视频，我们需要把坐标来源和证据范围写清楚。
3. **把烟雾框、火焰框、热像热点混为一类**：烟雾是早期预警目标，V/T 火点是本课题目标，类别和评价不能互换。
4. **只改网络模块来解决数据问题**：我们目前更大的风险是标签可靠性、阶段覆盖、视频泄漏和时序门控，应先把数据账本和独立视频评估做实。
5. **直接宣称跨场景泛化**：两篇论文的数据统计和测试集来源有重复迹象；赵迪论文的 7,969 总量与 6,541+3,357 正负和不一致，徐瑞擎论文的域测试数量也出现表格与正文不一致。引用数字前应回查原始图片、标注和哈希。

## 6. 对本课题实验设计的具体改写

| 阶段 | 本课题做法 | 产物 |
|---|---|---|
| 数据 | B1-B3 全部视频作为候选训练来源；逐图复核 V=`flame`、T=`hotspot`、无火、非火高温、`ignore`；B4 留作验收候选 | 来源哈希、视频/session 划分、阶段统计 |
| 训练 | 分别训练 V/T；先用 E2 作基线和初始化候选；固定随机种子、输入尺寸和阈值 | 权重、配置、日志、哈希 |
| 评估 | 按完整视频而非随机帧留出；报告 AP50/P/R 和阶段、小目标、弱火指标 | 独立视频报告 |
| 实时 | 逐帧检测后做 V/T 配对、轨迹确认和无火门控 | JSONL、CSV、带框视频 |
| 坐标 | B2 使用固定 LRF 参考查表；B4 只做近似画面核对；未知火点另立几何定位实验 | 坐标来源、置信状态、失败原因 |
| 论文 | 重点强调多机位 V/T 配对、视频级验证、轨迹连续性和证据边界 | 方法章节、消融表、局限性 |

## 7. 当前执行结论

前辈论文说明“检测模型后接多帧定位和机载软件”是可行的总体路线，但不能证明当前 B2/B4 已经具备稳定识别或独立坐标精度。当前先完成 B1-B3 全视频标签账本和完整视频划分，再训练大样本 V/T 模型；固定 B4 验收协议后，才决定是否引入公开数据或几何定位模块。
