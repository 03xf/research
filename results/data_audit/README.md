# 数据统计说明

统计来自实际发布的图片、标签与历史划分。图片按 SHA256 去重；同一图片的不同标签版本及不同类别定义分别保留。框数量按“图像内容＋标签内容＋类别映射”统计，不代表独立火灾数量。

E1/E2 使用 `0=smoke、1=flame`；C1/C2/C3/C4 和 B2 明火专用数据使用 `0=flame`。历史验证原标签使用 `0=smoke、1=flame`。类别解释以 `manifests/datasets.csv` 及逐图 `class_names` 为准，原始标签未重编号。

`bbox_size_definitions.csv` 的 COCO 风格统计使用原图像素面积；宽高阈值要求两个维度同时小于阈值。这些是候选统计口径，没有选定论文最终 tiny 定义。`bbox_quantiles.csv` 给出宽高、面积和面积比例分位数。

`split_leakage.csv` 在每个历史数据版本内部检查跨划分重叠，避免把不同实验使用相同图片误判为新泄漏；相邻帧检查采用不超过 2 秒的已有请求时间差，未把它冒充精确曝光 PTS。缺少身份和时间的样本无法完成对应检查，零条发现不表示已经证明独立。

未标注图片不计为负样本。空标签表示该版本没有标框，不能自动证明无火；明火专用版本中的空标签也可能包含烟雾。B3、B4 的逐帧北/南或东/西归属若未单独核实就留空，不能按批次把同一画面硬分给某个火点。
